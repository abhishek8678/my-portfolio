# Abhishek Kumar — Personal Portfolio

A sleek, responsive, and high-performance personal developer portfolio built with **React 19**, **Vite**, **Tailwind CSS v4**, **Framer Motion**, and **GSAP**. Featuring dual theme support (light and dark mode with glowing ambient gradients), smooth animations, and showcase of featured production projects.

---

## 🚀 Featured Projects

- **[Food Frenzy](https://github.com/abhishek8678/Food-Frenzy)** — *Production-Grade Full-Stack Dining Platform*
  - Engineered with **Spring Boot 3.4.2**, **Java 21**, **Thymeleaf**, and **PostgreSQL / H2**.
  - Dual-theme engine (dark mode & aesthetic white mode) with instant hydration.
  - Role-based security with **Google OAuth 2.0** and Spring Security filter chains.
  - End-to-end ordering, cart calculation, customer dashboard, and admin catalog management.
  - OpenAPI 3 / Swagger documentation and Dockerized containerization.

- **[RecruitAI — AI Recruitment Screener](https://github.com/abhishek8678/AI-Recruitment-Screener)**
  - Enterprise AI screening platform featuring a 70/30 Hybrid Scoring Engine (NVIDIA Llama-3.1 + TF-IDF) and an interactive Virtual Prep Room interview simulator.
  - Stack: React, FastAPI, NVIDIA LLM, Supabase.

- **[Movie Booking Application](https://github.com/abhishek8678/Movie-Booking)**
  - Full-stack movie booking platform with interactive seat selection, Stripe payments, JWT authentication, and QR ticket generation.
  - Stack: React, Node.js, Express, MongoDB, Stripe.

- **AI Powered News Aggregator**
  - Full-stack AI-driven platform aggregating real-time news from multiple APIs with automated cron scheduling.

- **Weather Dashboard Web App**
  - Responsive weather dashboard with live meteorological forecasting and interactive maps.

- **ScoreMate**
  - Comprehensive academic tracking dashboard with AI-driven analytics and grading insights.

## 💻 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone repository
git clone https://github.com/abhishek8678/my-portfolio.git

# Navigate into project directory
cd my-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
